设计说明

  • 与A/B的区别:默认不展示任何表格——主区一句话 + 三张卡就是全部必读信息(代理通不通 / 直连通不通 / 节点几个在线、选了谁);明细全部收进展开区,适合非技术朋友。
  • 断网文案走"安抚"路线:主标题直接说结论("外网暂时不可用"),副标题立刻给出两条定心丸(国内不受影响 / 在自动重试),展开后才解释原因与自救步骤。
  • 高度最矮:绿态默认约 190px(和现网绿态接近);展开 +170px。A/B 常驻通断网格,本方案把通断压缩成 "6 / 6 在线" 一个数字,想要明细再点。
  • 数据来源:与A/B一致;仅"直连通"需桥里新增轻量直连探测。
